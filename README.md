# PhishGuard AI

AI-assisted phishing protection for Chrome: an MV3 extension scans pages as you browse, a FastAPI backend scores them
(Random Forest + threat feeds + rules), and a dark security dashboard shows statistics, history and reports.
MIT licensed, all code original, no copyrighted assets or datasets.

```
extension/   Chrome MV3 extension (service worker, popup, warning page, options, optional page analysis)
backend/     FastAPI app (auth, scan API, SSRF guard, threat intel, rate limiting, admin vault)
ml/          Feature extraction, dataset generator, Random Forest training + explainability
dashboard/   Web console served by the backend at /dashboard/
database/    SQLite schema (database file is created at runtime, never committed)
tests/       pytest (ML, API, SSRF) + Node tests (extension logic, content script, fake-Chrome, live end-to-end)
docs/        DEPLOYMENT.md, SECURITY.md, ROADMAP.md
```

## Run locally in 3 minutes (no API keys needed)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                   # optional; edit to set passwords/keys
python -m ml.train                                     # trains the model (~3 s); also auto-runs on first start
uvicorn backend.app.main:app --port 8000
```
In development mode a random admin password is printed once in the server log (look for `DEV ONLY`).
Set `ADMIN_PASSWORD` and `ADMIN_MASTER_KEY` in `.env` to choose your own. Open http://127.0.0.1:8000/dashboard/.
Then load the extension (see `docs/DEPLOYMENT.md` section 3); it talks to `http://127.0.0.1:8000` by default.

## What each requirement maps to

| Area | Implementation |
|---|---|
| Scan + classify + 0-100 score | `backend/app/scanner.py` (safe 0-29, suspicious 30-69, phishing 70-100) |
| Warning page, history, whitelist, ON/OFF | `extension/warning.*`, `popup.*`, `options.*`, `background.js` |
| Random Forest, 28 URL features, typosquatting, keywords, IP, subdomains | `ml/features.py`, `ml/train.py` |
| Explainable results | Occlusion-based per-feature impact in `ml/predict.py`, plain-English reasons in every response |
| Safe Browsing / URLhaus / domain age / TLS / redirects | `backend/app/intel.py`, `backend/app/ssrf.py` |
| Graceful API failure | Every lookup returns `ok / disabled / unavailable`; scans still complete; the extension has an offline fallback |
| Auth, validation, rate limits, env config | `backend/app/main.py`, `security.py`, `config.py`, `.env.example` |
| Dashboard | Overview, history, threat reports, model metrics, settings, admin vault |

## Honest limitations (please read)

* **The bundled ML dataset is synthetic** (generated by `ml/dataset.py` from original templates, so it is licence-free).
  The reported ~99.9 % F1 is therefore **optimistic** and says little about real-world accuracy. For production, retrain on real
  feeds: `python -m ml.train --phish-csv feed.csv --legit-csv tranco.csv` (see `docs/DEPLOYMENT.md`).
* **Safe Browsing and URLhaus need free API keys.** Without them those sources report `disabled` and detection relies on ML + rules.
* "Real-time screen monitoring" is implemented as **page-structure analysis**, not screenshots or screen recording (see `docs/SECURITY.md`).
* The extension was tested against a fake Chrome API and the live backend, **not inside a real Chrome browser** in the build environment.
  Load it once yourself and run the manual checklist in `docs/DEPLOYMENT.md`.
* The backend has not been deployed to a cloud account by this build (no cloud credentials). `Dockerfile` and `render.yaml` are provided; the Docker image was not built in the sandbox.
